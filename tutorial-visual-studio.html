Tutorial Prático: POO em C# no Visual Studio

O que você vai construir: um sistema de cadastro de animais (Pet Shop) que usa os quatro pilares da POO — primeiro rodando no Console, depois com uma tela de verdade em Windows Forms.

Pré-requisito

Visual Studio 2022 Community instalado, com a carga de trabalho ".NET desktop development" marcada no instalador (confira em Visual Studio Installer → Modificar).

Parte 1 — Console App

Passo 1.1 — Criar o projeto

  1. Abra o Visual Studio e clique em Criar um novo projeto.
  2. Busque Aplicativo de Console e selecione o modelo com a etiqueta C#.
  3. Clique em Avançar.
  4. Nome do projeto: PetShopConsole.
  5. Estrutura: .NET 8.0 (Suporte de Longo Prazo).
  6. Clique em Criar.

O Visual Studio abre com Program.cs contendo:

Console.WriteLine("Hello, World!");
Por que não tem uma classe Program com Main?

Desde o .NET 6, o C# permite escrever o ponto de entrada direto, sem a "casca" de class Program { static void Main() { ... } }. É chamado de top-level statements. O compilador gera essa estrutura por baixo dos panos.

Passo 1.2 — Rodar pela primeira vez

Pressione Ctrl+F5 (executar sem depurar). Deve abrir uma janela de console mostrando Hello, World!. Pressione qualquer tecla para fechar.

Passo 1.3 — Criar a classe Animal

  1. No Gerenciador de Soluções, botão direito no projeto PetShopConsole.
  2. Adicionar → Classe...
  3. Nomeie Animal.cs e clique em Adicionar.
public abstract class Animal
{
    public string Nome { get; private set; }
    public int Idade { get; private set; }

    protected Animal(string nome, int idade)
    {
        if (string.IsNullOrWhiteSpace(nome))
            throw new ArgumentException("O nome do animal é obrigatório.");

        if (idade < 0)
            throw new ArgumentException("A idade não pode ser negativa.");

        Nome = nome;
        Idade = idade;
    }

    public abstract string FazerSom();

    public void Comer() => Console.WriteLine($"{Nome} está comendo.");

    public override string ToString() => $"{Nome} ({Idade} anos) - {GetType().Name}";
}
TrechoPilarPor quê
get; private set;EncapsulamentoNinguém de fora muda Nome ou Idade depois de criado
if (idade < 0) throw ...EncapsulamentoImpede que o objeto nasça com dado inválido
abstract classAbstraçãoNinguém faz new Animal(...); toda filha implementa FazerSom
protected Animal(...)HerançaSó pode ser chamado pelas classes filhas

Passo 1.4 — Criar Cachorro e Gato

Repita o Passo 1.3 para Cachorro.cs e Gato.cs.

public class Cachorro : Animal
{
    public Cachorro(string nome, int idade) : base(nome, idade) { }

    public override string FazerSom() => "Au au!";
}
public class Gato : Animal
{
    public Gato(string nome, int idade) : base(nome, idade) { }

    public override string FazerSom() => "Miau!";
}

O : base(nome, idade) chama o construtor da classe pai. Sem isso, o C# não compila.

Passo 1.5 — Usar as classes em Program.cs

List<Animal> animais = new List<Animal>
{
    new Cachorro("Rex", 3),
    new Gato("Mimi", 2)
};

foreach (Animal animal in animais)
{
    Console.WriteLine(animal);
    Console.WriteLine(animal.FazerSom());
    animal.Comer();
    Console.WriteLine();
}

Console.WriteLine("Pressione qualquer tecla para sair...");
Console.ReadKey();

Pressione Ctrl+F5. Saída esperada:

Rex (3 anos) - Cachorro
Au au!
Rex está comendo.

Mimi (2 anos) - Gato
Miau!
Mimi está comendo.

Isso é polimorfismo: a mesma linha animal.FazerSom() produz respostas diferentes, dependendo do tipo real do objeto guardado na lista.

Passo 1.6 — Encapsulamento protegendo o programa

Antes do Console.ReadKey();, adicione:

try
{
    Animal animalInvalido = new Cachorro("", -5);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Erro ao criar animal: {ex.Message}");
}

A regra que protege o objeto está dentro da classe Animal, em um único lugar.

Passo 1.7 — Desafio

Crie uma classe Passaro seguindo o mesmo padrão, com FazerSom() retornando "Piu piu!". Adicione um Passaro na lista e rode de novo.

  • O projeto PetShopConsole compila sem erros
  • A lista imprime nome, idade, som e "está comendo" para cada animal
  • Criar um animal com nome vazio gera o erro tratado, sem derrubar o programa
  • Você criou Passaro sozinho e ele aparece na lista

Parte 2 — Windows Forms

Até aqui, tudo rodou em texto. Agora vamos dar uma interface gráfica ao mesmo sistema.

Passo 2.1 — O que é Windows Forms

É uma tecnologia para criar janelas com controles visuais (botões, caixas de texto, listas). A diferença central para o Console: o programa passa a ser orientado a eventos — fica esperando o usuário clicar em algo, e só então executa o código correspondente.

Passo 2.2 — Criar o projeto Windows Forms

  1. Arquivo → Novo → Projeto...
  2. Busque Aplicativo Windows Forms, modelo com etiqueta C#.
  3. Nome do projeto: PetShopForms.
  4. Estrutura: .NET 8.0 (Suporte de Longo Prazo).
  5. Clique em Criar.

São dois projetos separados — o Visual Studio não mistura um com o outro automaticamente.

Passo 2.3 — Conhecendo o Designer

Três painéis importantes: Caixa de Ferramentas (Ctrl+Alt+X), Janela Propriedades (F4), e o Gerenciador de Soluções, onde Form1.cs esconde um Form1.Designer.cs gerado automaticamente.

Passo 2.5 — Preenchendo o ComboBox

  1. Clique no cmbTipo.
  2. Na Janela Propriedades, propriedade Items → clique nos três pontinhos ...
  3. Digite, uma por linha: Cachorro e Gato.
  4. Clique em OK.

Passo 2.6 — Trazendo as classes do outro projeto

O projeto PetShopForms ainda não conhece Animal, Cachorro nem Gato. Crie os três arquivos de novo (Adicionar → Classe...) com o mesmo conteúdo da Parte 1.

Para ir além

Uma forma mais elegante é criar um terceiro projeto do tipo Biblioteca de Classes e fazer os dois projetos referenciarem essa biblioteca, evitando código duplicado.

Passo 2.8 — Programando o botão Cadastrar

Dê um duplo clique em btnCadastrar no formulário — o Visual Studio gera o método btnCadastrar_Click.

private void btnCadastrar_Click(object sender, EventArgs e)
{
    string nome = txtNome.Text;

    if (!int.TryParse(txtIdade.Text, out int idade))
    {
        MessageBox.Show("Digite uma idade válida.", "Erro de validação");
        return;
    }

    Animal novoAnimal;

    try
    {
        if (cmbTipo.SelectedItem?.ToString() == "Cachorro")
            novoAnimal = new Cachorro(nome, idade);
        else if (cmbTipo.SelectedItem?.ToString() == "Gato")
            novoAnimal = new Gato(nome, idade);
        else
        {
            MessageBox.Show("Selecione o tipo do animal.", "Erro de validação");
            return;
        }
    }
    catch (ArgumentException ex)
    {
        MessageBox.Show(ex.Message, "Erro ao cadastrar");
        return;
    }

    _animais.Add(novoAnimal);
    lstAnimais.Items.Add(novoAnimal);

    txtNome.Clear();
    txtIdade.Clear();
    cmbTipo.SelectedIndex = -1;
}

Adicione o campo abaixo de public partial class Form1 : Form, antes do construtor:

private List<Animal> _animais = new List<Animal>();

Passo 2.9 — Programando o botão Fazer Som

Duplo clique em btnFazerSom:

private void btnFazerSom_Click(object sender, EventArgs e)
{
    if (lstAnimais.SelectedItem is Animal animalSelecionado)
    {
        MessageBox.Show(animalSelecionado.FazerSom(), $"{animalSelecionado.Nome} diz:");
    }
    else
    {
        MessageBox.Show("Selecione um animal na lista primeiro.", "Nenhum animal selecionado");
    }
}

Passo 2.10 — Rodando o programa completo

  1. Pressione F5.
  2. Digite um nome, uma idade, escolha "Cachorro", clique Cadastrar.
  3. Repita com "Gato" e outro nome.
  4. Clique em um item da lista para selecioná-lo.
  5. Clique em Fazer Som — a caixa de mensagem mostra "Au au!" ou "Miau!" conforme o tipo.
O que isso prova

O botão Fazer Som não sabe, e não precisa saber, se o item selecionado é um Cachorro ou um Gato — ele só chama FazerSom() e deixa o objeto responder. Polimorfismo, agora numa interface gráfica de verdade.

Passo 2.11 — Desafio final

Escolha ao menos um:

  1. Adicione Passaro ao cmbTipo e ao cadastro.
  2. Adicione um botão Remover que apaga o animal selecionado da lista.
  3. Adicione um Label que mostra quantos animais já foram cadastrados.

O que você praticou

  • Encapsulamento — propriedades com private set e validação no construtor, no Console e capturando o erro na tela gráfica.
  • Herança — Cachorro e Gato reaproveitando Nome, Idade e Comer().
  • Polimorfismo — a mesma chamada FazerSom() respondendo diferente, do foreach ao clique de botão.
  • Abstração — Animal como classe abstrata, sem que quem usa a lista precise saber os detalhes de cada tipo.
